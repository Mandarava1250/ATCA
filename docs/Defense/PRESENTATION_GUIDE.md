## 导出为PDF的方法

### 方法1：使用Microsoft PowerPoint（推荐）

1. 双击打开 `华夏营造技术演示.pptx`
2. 点击菜单 **文件** → **导出**
3. 选择 **创建PDF/XPS**
4. 选择保存位置，点击 **发布**

### 方法2：使用WPS Office

1. 用WPS打开PPTX文件
2. 点击 **文件** → **另存为**
3. 选择PDF格式 (.pdf)
4. 点击保存

### 方法3：使用在线工具

访问以下网站，上传PPTX文件即可转换为PDF：
- https://www.ilovepdf.com/ppt_to_pdf
- https://www.aconvert.com/document/pptx-to-pdf/

### 方法4：使用LibreOffice（免费开源）

```bash
# 安装LibreOffice
# Windows: 从官网下载安装包
# macOS: brew install --cask libreoffice

# 转换命令
libreoffice --headless --convert-to pdf --outdir . 华夏营造技术演示.pptx
```

## 修改演示文稿

### 如果只需微调内容

直接用PowerPoint或WPS打开PPTX文件编辑即可。

### 如果需要大幅修改或添加图表

1. 编辑 `presentation.md` 文件（使用VS Code + Marp插件）
2. 运行命令重新生成PPTX：

```bash
# 安装Marp CLI
npm install -g @marp-team/marp-cli

# 生成PPTX
marp --pptx presentation.md

# 生成PDF
marp --pdf presentation.md
```
