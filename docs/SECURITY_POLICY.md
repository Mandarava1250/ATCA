# 华夏营造 - 安全策略文档

## 1. 概述

本文档定义了华夏营造项目的安全策略，旨在保护系统免受各种网络威胁，包括SQL注入、XSS、暴力破解、权限提升、恶意软件注入、钓鱼攻击和ARP欺骗等。

## 2. SQL注入防护

### 2.1 实施措施

| 措施 | 描述 | 实施位置 |
|------|------|----------|
| 参数化查询 | 所有数据库操作使用参数化查询，禁止字符串拼接 | `src/config/database.ts` |
| ORM框架 | 使用TypeORM或类似ORM框架进行数据库操作 | 后端数据层 |
| 输入验证 | 使用Zod进行严格的输入验证 | `src/middleware/validation.ts` |
| SQL注入检测 | 中间件检测常见SQL注入模式 | `src/middleware/security.ts` |
| 最小权限原则 | 数据库用户仅授予必要权限 | 数据库配置 |

### 2.2 检测规则

- 检测单引号逃逸模式：`' OR 1=1--`
- 检测SQL关键字：`UNION SELECT`, `DROP TABLE`, `EXEC`
- 检测时间延迟注入：`WAITFOR DELAY`, `SLEEP`

### 2.3 响应措施

- 检测到SQL注入尝试时返回HTTP 400错误
- 记录安全日志并通知安全团队
- 暂时阻止来源IP访问

## 3. XSS（跨站脚本攻击）防护

### 3.1 实施措施

| 措施 | 描述 | 实施位置 |
|------|------|----------|
| 输出编码 | 对所有用户生成内容进行HTML编码 | `src/middleware/security.ts` |
| CSP配置 | 配置内容安全策略头 | `src/middleware/security.ts` |
| HttpOnly Cookie | 会话Cookie设置HttpOnly标志 | `src/middleware/auth.ts` |
| Secure Cookie | HTTPS环境下设置Secure标志 | `src/middleware/auth.ts` |
| 输入验证 | 严格验证所有用户输入 | `src/middleware/validation.ts` |

### 3.2 CSP配置

```
Content-Security-Policy: 
  default-src 'self';
  script-src 'self' 'strict-dynamic';
  style-src 'self' 'unsafe-inline';
  img-src 'self' data: https:;
  font-src 'self';
  connect-src 'self' https:;
  object-src 'none';
  base-uri 'self';
  form-action 'self';
```

### 3.3 安全响应头

```
X-Frame-Options: DENY
X-Content-Type-Options: nosniff
X-XSS-Protection: 1; mode=block
Referrer-Policy: strict-origin-when-cross-origin
Cross-Origin-Resource-Policy: same-origin
```

## 4. 暴力破解防护

### 4.1 密码策略

| 要求 | 说明 |
|------|------|
| 最小长度 | 12位 |
| 最大长度 | 128位 |
| 数字 | 至少1个 |
| 大写字母 | 至少1个 |
| 小写字母 | 至少1个 |
| 特殊字符 | 至少1个（!@#$%^&*等） |
| 常见模式 | 禁止包含常见弱密码模式 |

### 4.2 账户锁定机制

| 参数 | 值 |
|------|-----|
| 最大尝试次数 | 5次 |
| 锁定时长 | 15分钟 |
| 时间窗口 | 10分钟内计数 |

### 4.3 速率限制

| 端点 | 限制 |
|------|------|
| `/auth/login` | 15分钟内10次 |
| `/auth/register` | 15分钟内5次 |
| 通用API | 15分钟内200次 |

## 5. 权限提升防护

### 5.1 角色定义

| 角色 | 权限 |
|------|------|
| `admin` | 所有资源的全部权限 |
| `moderator` | 用户管理、内容审核 |
| `user` | 个人资源管理、基础功能 |
| `guest` | 只读访问公共资源 |

### 5.2 访问控制措施

| 措施 | 描述 |
|------|------|
| 角色检查 | 中间件验证用户角色 | `src/middleware/accessControl.ts` |
| 权限检查 | 细粒度权限验证 | `src/middleware/accessControl.ts` |
| 资源所有权 | 验证资源归属 | `src/middleware/accessControl.ts` |
| 会话超时 | 24小时自动过期 | `src/middleware/accessControl.ts` |

### 5.3 权限审计

- 定期审查用户权限分配
- 记录所有权限变更操作
- 最小权限原则应用

## 6. 恶意软件注入防护

### 6.1 文件上传验证

| 验证项 | 说明 |
|--------|------|
| 文件类型 | 白名单验证MIME类型 |
| 文件扩展名 | 白名单验证扩展名 |
| 文件大小 | 按类型限制大小 |
| 文件内容 | 检查文件头和危险内容 |

### 6.2 允许的文件类型

| 类型 | MIME类型 | 扩展名 | 大小限制 |
|------|----------|--------|----------|
| 图片 | image/* | .jpg,.png,.gif,.webp,.svg | 10MB |
| 头像 | image/* | .jpg,.png,.gif,.webp | 2MB |
| 3D模型 | model/* | .glb,.gltf,.obj,.stl | 50MB |
| 文档 | application/pdf, text/* | .pdf,.txt | 10MB |

### 6.3 危险文件黑名单

```
.exe, .dll, .bat, .cmd, .com, .scr,
.msi, .js, .html, .php, .asp, .jsp,
.py, .sh, .bash, .ps1, .vbs, .jar,
.apk, .app, .dmg, .iso, .zip, .rar,
.7z, .tar, .gz, .bz2, .xz, .cab
```

### 6.4 服务器安全

- 上传目录设置只读权限
- 禁止执行上传目录中的文件
- 定期扫描上传文件

## 7. 钓鱼攻击防护

### 7.1 邮件认证

| 协议 | 描述 |
|------|------|
| SPF | 发件人策略框架 |
| DKIM | 域名密钥识别 |
| DMARC | 基于域名的邮件认证 |

### 7.2 用户教育

- 定期发布安全提醒
- 提供钓鱼识别培训
- 设置安全意识公告

### 7.3 域名保护

- 注册相似域名防止仿冒
- 监控域名声誉
- 使用HTTPS加密传输

## 8. ARP欺骗防护

### 8.1 网络层防护

| 措施 | 描述 |
|------|------|
| 静态ARP条目 | 关键系统使用静态ARP |
| ARP检测 | 部署ARP欺骗检测工具 |
| 网络监控 | 监控异常ARP活动 |
| 网络分段 | 限制ARP欺骗影响范围 |

### 8.2 检测指标

- 异常ARP请求频率
- 重复MAC地址出现
- 网关MAC地址变更

## 9. 安全事件响应计划

### 9.1 响应流程

```
检测 → 确认 → 隔离 → 分析 → 修复 → 恢复 → 复盘
```

### 9.2 事件分级

| 级别 | 描述 | 响应时间 |
|------|------|----------|
| P0 | 系统完全瘫痪 | 立即 |
| P1 | 数据泄露/严重漏洞 | 1小时内 |
| P2 | 服务中断/功能异常 | 4小时内 |
| P3 | 安全告警/潜在威胁 | 24小时内 |

### 9.3 响应团队

| 角色 | 职责 |
|------|------|
| 安全负责人 | 协调响应工作 |
| 技术负责人 | 技术分析与修复 |
| 运营负责人 | 服务恢复与沟通 |
| 法务负责人 | 合规与法律事宜 |

### 9.4 响应步骤

1. **检测阶段**
   - 监控安全日志
   - 识别异常行为
   - 初步评估影响

2. **确认阶段**
   - 验证威胁真实性
   - 评估影响范围
   - 确定事件级别

3. **隔离阶段**
   - 隔离受影响系统
   - 阻止攻击持续
   - 保护证据

4. **分析阶段**
   - 分析攻击路径
   - 确定漏洞原因
   - 收集取证信息

5. **修复阶段**
   - 修补漏洞
   - 强化安全措施
   - 更新安全策略

6. **恢复阶段**
   - 恢复服务
   - 监控系统状态
   - 验证修复效果

7. **复盘阶段**
   - 总结经验教训
   - 更新安全文档
   - 培训团队成员

### 9.5 沟通流程

| 受众 | 沟通内容 | 时间要求 |
|------|----------|----------|
| 内部团队 | 事件详情与状态 | 持续更新 |
| 管理层 | 影响评估与处理进度 | 定期汇报 |
| 用户 | 服务状态与安全建议 | 必要时通知 |
| 监管机构 | 合规报告 | 按法规要求 |

## 11. 日志与监控

### 11.1 日志记录

| 日志类型 | 内容 | 保留时间 |
|----------|------|----------|
| 访问日志 | 请求详情、状态码 | 30天 |
| 安全日志 | 安全事件、告警 | 90天 |
| 审计日志 | 权限变更、关键操作 | 180天 |

### 11.2 监控指标

| 指标 | 阈值 | 告警级别 |
|------|------|----------|
| 4xx错误率 | >5% | P2 |
| 5xx错误率 | >2% | P1 |
| 登录失败次数 | >10次/分钟 | P2 |
| 请求频率异常 | >1000次/分钟 | P2 |

### 11.3 告警机制

- 实时告警通知
- 多渠道通知（邮件、短信、即时通讯）
- 告警分级处理
