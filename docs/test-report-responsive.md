## 已知限制

1. **文本折叠实现**: 使用CSS的`-webkit-line-clamp`属性，在旧版浏览器（<Chrome 76）可能不支持
2. **服务端渲染(SSR)**: 在SSR环境中，文本行数测量可能不准确
3. **动态内容**: 如果文本内容通过JavaScript动态改变，需要手动调用`measureLineCount()`方法
